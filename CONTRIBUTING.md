# Contributing

This repository is one application in the BDPL LabTools family. The
conventions are set in the hub, [sul-dlss/bdpl-labtools](https://github.com/sul-dlss/bdpl-labtools):
read its [CONTRIBUTING.md](https://github.com/sul-dlss/bdpl-labtools/blob/main/CONTRIBUTING.md)
and the working rules in [CLAUDE.md](CLAUDE.md) here before your first change.

The one rule that governs everything: **nothing reaches `main` except through
a pull request**, and GitHub enforces it for everyone, admins included.

New here? The hub's
[collaborator setup guide](https://github.com/sul-dlss/bdpl-labtools/blob/main/docs/collaborator-setup.md)
covers accounts, the `gh` tool, git identity and the daily workflow.
