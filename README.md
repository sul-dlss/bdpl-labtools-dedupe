# BDPL LabTools: Dedupe

Deduplication tool for digital archivists in the Born-Digital Preservation Lab (BDPL) at Stanford Libraries.
Part of the [BDPL LabTools](https://github.com/sul-dlss/bdpl-labtools) family.

## Purpose

Identify duplicate files within and across accessions so archivists can decide what to keep, flag or remove before transfer.

## Status

Scaffolding only. Requirements and design are being worked out in `docs/`.
